# Responsible security-tool use

This repository contains port scanners, URL analysis, DNS utilities, and other tools that can generate network traffic or inspect systems and content.

Use them only on systems, networks, files, and URLs that you own or have explicit permission to test. Do not use them to bypass access controls, evade detection, disrupt services, or collect data without authorization. You are responsible for complying with applicable laws, contracts, and organizational policies.

The tools use simple heuristics and may produce false positives or false negatives. They are provided for education and authorized troubleshooting, not as a substitute for a professional security assessment. The authors accept no responsibility for misuse, damage, data loss, or legal consequences.

The Flask backup endpoint is intended for local development. It has no authentication and must not be exposed to an untrusted network without a thorough security review and additional controls.
